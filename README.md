# 🎓 Gestor de Estudiantes y Beneficios

Aplicación de consola desarrollada en C++ que permite administrar estudiantes, usuarios y beneficios académicos mediante persistencia de datos en archivos binarios.

Este proyecto fue realizado con fines académicos para aplicar estructuras de datos, manejo de archivos, modularización de programas y programación procedural.

---

## 🎯 Objetivo del Proyecto

Desarrollar un sistema capaz de registrar usuarios, gestionar información estudiantil y administrar beneficios asociados, manteniendo la información almacenada de manera persistente mediante archivos.

---

## 🚀 Funcionalidades

### 👤 Gestión de Usuarios
- Registro de nuevos usuarios.
- Validación de correos electrónicos duplicados.
- Asignación automática de créditos iniciales.
- Consulta de usuarios registrados.

### 🎓 Gestión Académica
- Administración de estudiantes.
- Registro y procesamiento de información académica.
- Organización de datos mediante estructuras (`struct`).

### 💾 Persistencia de Datos
- Lectura y escritura de archivos binarios (`.dat`).
- Conservación de la información entre ejecuciones.
- Búsqueda y validación de registros almacenados.



